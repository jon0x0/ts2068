# r55 independent projectile updates

Normal/spread bolts now move and draw on an interrupt phase separate from player publication and the boss/world loop. This replaces r54's three native travel steps per slow world tick. Normal clear-space motion is now one 8-pixel cell per projectile phase: the component test from x=8 shows 21 successive visible positions (9..29), rather than approximately three 48-pixel jumps. Original global glyphs 46/47/48 and their legal ECM colours are retained and checked against native bytes. This is more frequent visible movement, not a new set of bolt artwork frames.

The alternate player IRQ path captures controls/fire as before, then services the projectile phase when gameplay is active and background capture/copy is idle. Player movement code, distances, selected-key handling, native joystick support and the separate timed launch plume remain unchanged. Eight active slots maximum are serviced per phase, round-robin across the existing sixteen slots. This bounds per-interrupt work; full-pool service and continuous scenery copies can reduce cadence. Charged beams and other weapon pools retain their existing timing.

The projectile renderer owns only bytes that it actually drew onto blank black-paper scanlines. It skips occupied bytes, records an exact two-byte ownership mask per bolt, preserves added non-bolt bits during erasure, and clears empty space to normal black. Every world-copy entry removes overlays before the native copy. A conservative ship exclusion avoids capturing projectile pixels in the player's independent saved background. No whole-screen scan, per-frame allocation or new art conversion is involved.

Contacts use the native metadata map, including the second cell of each glyph. Hits are queued; IRQ drawing never calls the native non-reentrant hit resolver. The main loop resolves contacts through A490. A saved actor script signature rejects stale queued targets. Component tests check damage occurs once and that replacing an actor before handoff does not damage the replacement. Solid terrain releases the bolt without invoking actor damage.

Runtime engine: 575 bytes at DOCK2:5880..5ABE, outside retained ECM rows and HUD cache. Its cold image is temporarily stored at DOCK7:F100, installed after native HOME code is copied, and restored before changing resident level banks. This avoids overwriting the cold native code at HOME9880. The 128-byte state block is DOCK2:5F80..5FFF; private stack below 5CA0 remains separate from L5's shader stack/scratch and the HOME player/IRQ stacks. Component low-water is 5C96. Static owned-range checks preserve artwork, player engine/phase cache and boss shaders. The shared-bank shims perform no stack access while their stack bank is hidden.

Build: `python scripts/build_projectile_clock.py`. Final serial verification: `python scripts/run_projectile_clock_final.py`. Packaging/owned-range/TAP checks: `python scripts/finalize_projectile_clock.py`. Derived only from frozen r54; reference projects and source archives remain unchanged. This version targets the expanded-RAM disk build. The existing stock 64KB cartridge is unchanged.
