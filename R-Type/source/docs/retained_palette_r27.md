# Correct retained enemy palettes, r27

The blue rectangles in levels2/4 were a game-side retained-colour bug. Direct sprite drawing used the new8x1 enemy palette dictionary, while scrolling/restoration still interpreted stored palette indices as original Spectrum attributes. Index12 became attribute0C (green ink, blue paper) instead of dictionary row12 (bright green on black). Even blank portions of those cells then showed blue paper. A full-screen redraw could not fix repeated misdecoding; the earlier r26 clean-redraw diagnostic is superseded.

The fix separates native attributes, terrain rows and retained enemy colours. The first16 constant enemy rows are stored as actual native ink/brightness values for speed. Other enemy IDs use90..FF (IDs0..111) or10..1F (IDs112..127), decoded through the DOCK1 dictionary. Terrain remains80..8F. Reserved low tokens are checked against the original common and non-solid terrain colours. Native common colours are [3,7,66,67,68,69,70,71], so the reservation does not collide.

The initial background writer encodes the retained token; whole-cell restoration, per-scanline decoding, fine-scroll boundaries and incoming columns all recognize it. Group-style edits and vertical terrain markers apply only to terrain tokens. Enemy source bounds distinguish the original graphics range from separately expanded sprite pools, excluding terrain/map/descriptor memory between them. Source geometry and bitmaps are unchanged. Native flat fills remain unrolled; multicolour copies process four rows per loop.

Actual Fuse1.10 captures of the level4 scene have424 green-on-blue attribute bytes before and zero after. The level2 firing stress route records110 incorrect native copies in redraw-only r26 and zero in the corrected build. Stored captures are under build/ecm_native/probe_1300_joy_l4_before.*, *_l4_palette_r27.* and *_l2_palette_r27.*. build/fullgame/l2_retained_comparison.json records the stress route. The same route diverges in timing/random state, so update counts are not a controlled FPS benchmark; no speedup is claimed.

All256 token values, all128 enemy row IDs, positive/negative expanded-pool bounds, mixed fast paths and8x1 copies are tested by verify_retained_palette.mjs. All10416 native enemy draw/clip/flip cases, eight8000-refresh gameplay runs, music/control tests, number-key starts, transitions, ending/restart,512KB loader/readback/alias rejection and116 title pictures pass. Full release is still hardware-untested.

Use build/fullgame/RType_TS2068_ECM_fullgame_TSPico512_r27.zip for the full512KB game and all per-level Fuse previews. Direct corrected previews are build/fullgame/previews_r27/Level_2_palette_fix_r27.dck and Level_4_palette_fix_r27.dck (all eight are present). Previews stop at a stage boundary; full number selection/progression needs TSPico512. The64KB read-only r24 release is unchanged; this bug was in the full-game dictionary format.

Reproduce from prepared assets with RTYPE_TITLE_DELTA=1 python scripts/build_all_ecm_levels.py, then python scripts/validate_retained_release.py. The main scripts/build_fullgame.py now defaults to the current title/selector flags and includes retained validation. The publisher checks matching palette-validation hashes. Normal r22 defaults still rebuild exactly.
