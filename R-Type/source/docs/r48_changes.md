# R48 integration and validation notes

Emulator-validated hardware test build: build/fullgame/compiled_game_r48/RType_TS2068_r48.zip. Physical validation is pending.

The 512KB disk build now has one-pixel player motion inside gameplay. It uses the existing native key-definition table and merges both native joystick ports. QAOP is fixed only in the separate relocatable-delta trial. The game draws the centre ship pose using eight horizontal phases at arbitrary raster Y. Native AI, companions and weapons retain their original character-grid coordinates, rounded to the player position; this is not a rewrite of every projectile into pixel coordinates.

The player compositor saves/restores the background, uses a local10-byte by32-raster backing patch during a scene copy, and publishes final changed bitmap/ECM bytes without a visible erase pass. Collision tests inspect actual covered pixels; sharing an8x1 cell alone does not imply a collision. A stationary player also receives collision checks when the world changes. IRQ sampling is nominally every second video interrupt; main work can delay interrupts, so this is not a constant30/60fps claim.

Fast normal fire releases are queued and allocated in the native16-slot projectile table between slow world updates. Charging and charged release remain native. A deterministic test of eight100ms press/release pairs produces exactly eight normal shots (seven from the IRQ path), and a later held press produces exactly one charged beam. Projectile drawing still follows the world update cadence.

Bellmite uses the approved H dark-blue planned edge, deeper organic colours and the selected96x96 machinery core. Pixel coverage fills the former whole-cell overlap cuts. Shared ECM cells retain foreground pair priority, so overlap colours can still merge. Two768-byte precomputed row-pair caches avoid repeated bitmap/colour decoding and horizontal reversal. The native unowned core path remains fast.384 direct native normal/flipped/clipped/owner/flash comparisons reproduce the preceding compositor's bitmap and colour output; the flash input is initialized in both references, and R48 explicitly samples it before banking. The700-update boss route takes32341 refreshes versus36820 for R47. This is a comparison with the preceding mask compositor, not a general claim that the entire game is faster than r44.

Working data and code stay within each resident64KB region of the existing512KB allocation. Bank7 owns codeE400..ED7F, centre phasesED80..F07F, backingF100..F37F, level5 horizontal row pairsF380..F67F, variables/scratchF680..F87F and collision snapshotF880..FAFF. Bank7 FB00..FBBF mirrors the HOME gateway; FBC0..FBDF initializes low HOME state; the original cache loader tailFBE0..FC9F remains intact. The mirrored FD20..FD47 IRQ entry maps HOME before storing the original bank and executes a matching exit after restoring bank7. The native reversal table is rebuilt in HOME5D00 and continuously checked.

The graphics helper's private stack uses the unused DOCK2 tail while attributes are mapped. The player gateway uses HOME5CA0..5CF0. Interrupts stay disabled while that low stack would be hidden by DOCK2 mapping. No loader, stack or working variables rely on writable cartridge ROM: this integration specifically targets the existing expanded-RAM disk build. The older stock64KB cartridge output has not been updated.

The separate Relocatable_delta_QAOP_TS2068.tap is a native, stock-machine movement trial on a black background, with64 cached transitions and both joystick ports. It is not an alternative full game. Its825-frame byte-exact controls test and common-pixel write checks pass; it performs zero visible writes while stationary.

Hardware testing is still required. Emulator route tests use invulnerability only where stated; a separate test exercises the real death/respawn handler without a death bypass. Original archives and reference projects remain unchanged.


Final gates: all eight boss encounters complete700 updates each (unchanged regions reused by exact byte identity; level5 rerun with the new caches). Full progression/ending/second circuit takes51556 emulated refreshes,128 transferred blocks, all eight levels reused from RAM,16520 executable-bank/reversal audits and15 core/workspace guards. Selected-level3/8 game-over restarts reuse resident assets without tape entry. The four loader-error controls are inherited from the byte-identical bootstrap/loader. Packaged72 asset pages pass length, hash and XOR checks. Actual controls testing covers redefined Z/X/C/V bindings, diagonal movement, both native joystick ports and opposing inputs. A separate real death/respawn test consumes the pixel-hit flag and clears it for the next life. The standalone cached trial and its baseline are both included.
