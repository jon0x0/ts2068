R-Type controls

Set movement keys: press Enter on the title screen and answer each prompt. Suggested: O left, P right, Q up, A down, Space fire, Enter missile / Force action. Follow the on-screen prompt order. Keyboard and native joystick stay active together.

Start / fire: Space or joystick Fire. L, then 1-8: select a level (browser switches cartridges; resets that level). B, release, B: jump to the current boss fight. Collect the offered weapon pickup. M: music on/off. Shift-P: pause/resume, with a Paused display. Press and release each command.

Virtual DPad: drag for directions, hold Fire; use the action buttons beside it. USB gamepad directions and Fire are supported. The Force / missile touch button assumes Enter was selected for that action. Keyboard bindings are chosen in the game, not forced by the player.

Click or press a key to enable browser audio. Sound On/Off mutes browser output; M toggles game music separately. The level selector is always available. Each physical cartridge contains one level; L switching belongs to this browser wrapper or the disk edition.

Play on a TS2068 with TSPico

Download the TSPico full-game archive. This edition uses the full 512KB RAM to load and cache the entire eight-level game. You can preload all levels, or load and play one level at a time; loaded levels remain cached in RAM. Extract the archive into the SD card /TAP/ directory, keeping the complete rtype/ folder, then reset and launch rtype/rt.tap.
