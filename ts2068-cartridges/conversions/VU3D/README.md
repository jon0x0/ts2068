# VU-3D cartridge conversion

[Release page](https://jon0x0.github.io/ts2068/ts2068-cartridges/conversions/VU3D/) · [Run in TSRun](play/) · [Josef’s WU-3D](https://josef-jelinek.github.io/WU-3D/)

The final August 7, 2026 cartridge, including the wineglass example and Shade keyboard fix, from [the TS2068 discussion](https://ts2068.groups.io/g/main/topic/120637831?msg=9614#msg9614). The original conversion predates this publication; no conversion builder source was recovered. Technical details, downloads and credits are on the release page.

Files were copied unchanged from the existing cartridge archive. `VU3D-rom.bin` is the DCK payload; `VU3D256Kbit.bin` is the supplied 32 KB EPROM image. Checksums are in SHA256SUMS.txt. Serve the repository over HTTP to run the browser player.
