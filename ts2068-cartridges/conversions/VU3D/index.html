The finished conversion

This is the August 7, 2026 menu version shared in the TS2068 discussion. It includes the wineglass example and the direct keyboard-scanning fix for the Shade prompts. The earlier diagnostic and prototype cartridges are omitted.

How it works

The original BASIC startup is retained, with tape loading replaced by an LZSS-style compressed screen and program in DOCK ROM. A HOME-RAM bootstrap at $6840 copies a decompressor to $6900. It briefly maps cartridge pages while reconstructing the screen at $4000 and program at $7800, then restores HOME memory and resumes VU-3D.

The routine at $8061 is patched to use a keyboard scanner at $69C0, avoiding the interrupt-driven LAST_K wait that could hang the Shade options.

Two browser experiences

TSRun runs the actual Z80 cartridge using Josef Jelinek’s TS2068 emulator. Click inside the emulator before typing; its Keyboard control shows the TS2068 layout. Reset restarts the cartridge.

Josef Jelinek’s WU-3D is a separate native web recreation with mouse interaction and higher-resolution rendering. For its shaded built-in demonstration, the discussion gives: 2, X, 6, P, S, A, L, G. WU-3D source.
