# Infocom collection: source and attribution

The Planetfall/Zork I disk is included at the project owner's request as a
separate historical-software collection. It is not an original MIT-licensed
game implementation. Infocom story files and the original interpreter retain
their respective rights; the project's license does not grant rights in them.
Availability in an archive is not a public-domain declaration.

Sources: [Infocom catalog](https://eblong.com/infocom/),
[CP/M interpreter source](https://eblong.com/infocom/interpreters/cpm80.zip),
[Planetfall release 37 / serial 851003](https://eblong.com/infocom/gamefiles/planetfall-r37-s851003.z3),
[Zork I release 88 / serial 840726](https://eblong.com/infocom/gamefiles/zork1-r88-s840726.z3).

The interpreter is configured for this project's ADM-3A console and detects
64/80 columns at startup. The game disk manifest records source/build hashes.
Each game requires its COM interpreter and matching DAT story. SAVE/RESTORE
write CP/M files; retain the outer disk using TPSAVE, Fuse Save/Save As, or
browser download as appropriate. Utility-only alternatives are also supplied.
