Click the screen to type directly. Backspace/Delete erase a character; Shift+C gives CP/M Ctrl-C. Plain 0 types zero. Download the disk as DSK or TAP before closing this page. A reset retains the current disk; opening another disk restarts CP/M.

Functional disk adapter for this CP/M port. Disk changes are in browser memory until downloaded; DSKs open in Fuse/Oliger; complete CP/M TAPs open with the modern TSPico protocol. Select all TAPs together to open a saved chunk set or preload volumes.
