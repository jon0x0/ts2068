Infocom collection: source and attribution

The Planetfall/Zork I disk is included at the project owner's request as a separate historical-software collection. It is not an original MIT-licensed game implementation. Infocom story files and the original interpreter retain their respective rights; the project's license does not grant rights in them. Availability in an archive is not a public-domain declaration.

Sources: Infocom catalog, CP/M interpreter source, Planetfall release 37 / serial 851003, Zork I release 88 / serial 840726.

The interpreter is configured for this project's ADM-3A console and detects 64/80 columns at startup. The game disk manifest records source/build hashes. Each game requires its COM interpreter and matching DAT story. SAVE/RESTORE write CP/M files; retain the outer disk using TPSAVE, Fuse Save/Save As, or browser download as appropriate. Utility-only alternatives are also supplied.
