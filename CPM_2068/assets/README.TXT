TS2068 CP/M 2.2 - 64 columns

DIR                 List files
STAT                Show free space
COLOR               List 64-column color schemes; COLOR 0..7 selects
PIP COPY.COM=HELLO.COM   Copy a file
TYPE README.TXT     Read this file
MEMTEST             Check RAM behind both display planes
SUBMIT DEMO         Assemble HI.ASM and load HI.COM
HI                  Run the assembled example
ED                  Editor

The emulator RAM disk is volatile; reload the cartridge to restore it.
The Oliger build uses a separate 160K floppy image in JLO drive 0.
Use Fuse's JLO disk Save/Save As menu to preserve floppy changes.
Warm boot preserves the current disk. Never format this disk in SAFE DOS.
